## ขั้นตอนอัปเดตบน GitHub

1. แตกไฟล์ `planet-age-cycle-v0.4.0-update-only.zip`
2. เปิดโฟลเดอร์ `planet-age-cycle-v0.4.0-update-only`
3. เข้า Repository และเลือก **Add file → Upload files**
4. ลากไฟล์และโฟลเดอร์ทั้งหมดไปวาง
5. ยืนยันการแทนที่ไฟล์ชื่อเดิม
6. Commit ไปที่ Branch `main`
7. รอ GitHub Pages เผยแพร่ประมาณ 1–3 นาที
8. ปิดหน้า WebApp เดิมแล้วเปิดใหม่

## สำคัญ: Service Worker

เนื่องจากเป็น PWA หากยังเห็นหน้าเก่า ให้ทำตามลำดับนี้:

1. รีเฟรชหน้าเว็บหนึ่งครั้ง
2. ปิดแท็บแล้วเปิดใหม่
3. หากยังไม่เปลี่ยน ให้ล้าง Site Data ของเว็บไซต์ แล้วเปิดใหม่
