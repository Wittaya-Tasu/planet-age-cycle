| `README.md` | คู่มือเวอร์ชันล่าสุด |

## วิธีอัปโหลด

1. แตกไฟล์ `planet-age-cycle-v0.7.0-update-only.zip`
2. เปิดโฟลเดอร์ `planet-age-cycle-v0.7.0-update-only`
3. เข้า Repository `planet-age-cycle`
4. เลือก **Add file → Upload files**
5. ลากไฟล์และโฟลเดอร์ทั้งหมดไปวางที่ระดับบนสุดของ Repository
6. ยืนยันการแทนที่ไฟล์เดิม แล้ว Commit
7. รอ GitHub Pages เผยแพร่
8. ปิดหน้า WebApp เดิม แล้วเปิดใหม่หรือทำ Hard Refresh

## จุดที่ควรทดสอบหลังอัปเดต

- วันอาทิตย์: ต้องเห็น `✓` ที่พระพฤหัสบดี และ `!` ที่พระอังคาร ทั้งแถบหลักและแถบย่อย
- วันจันทร์: ต้องเห็น `✓` ที่พระพุธ และ `!` ที่พระพฤหัสบดี
- วันอังคาร: ต้องเห็น `✓` ที่พระศุกร์ และ `!` ที่พระอาทิตย์
- วันพฤหัสบดี: ต้องเห็น `✓` ที่พระอาทิตย์
- วันศุกร์: ต้องเห็น `✓` ที่พระอังคาร และ `!` ที่พระเสาร์
- วันเสาร์: ต้องเห็น `!` ที่พระศุกร์
- Timeline ต้องมี 8 แถว เริ่มจากดาวเกิด และมีช่วงอายุด้านขวาทุกแถว
