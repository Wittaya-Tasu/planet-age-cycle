# อัปเดต Planet Age Cycle v0.3.0

ชุดนี้ออกแบบให้วางทับ Repository `Wittaya-Tasu/planet-age-cycle` เวอร์ชัน 0.2.0

## สิ่งที่เพิ่ม

| ส่วน | รายละเอียด |
|---|---|
| เวลาเกิด | รับชั่วโมงและนาทีเกิด |
| เวลาเป้าหมาย | ใช้คำนวณจุดเปลี่ยนช่วงภายในวันได้แม่นยำขึ้น |
| ปฏิทินจริง | แถบหลักใช้วันครบรอบปีจริง และแถบย่อยแบ่งสัดส่วนภายในแถบหลัก |
| 29 กุมภาพันธ์ | ปีปกติใช้ 28 กุมภาพันธ์ชั่วคราว และกลับเป็น 29 กุมภาพันธ์ในปีอธิกสุรทิน |
| คำพยากรณ์ | โหลดข้อมูล 64 ช่อง โดยมีต้นฉบับ 63 ช่องและ Placeholder 1 ช่อง |
| สถานะผล | รองรับ ดี, ไม่ดี, ดีและไม่ดี และไม่ระบุ |
| ความสัมพันธ์วันเกิด | แสดงเฉพาะค่าที่มีในตารางต้นฉบับ ค่าที่ไม่มีไม่แสดง |
| วันเริ่ม–สิ้นสุด | แสดงวันที่จริงของช่วงปัจจุบันและช่วงที่เลือก |
| ช่วงถัดไป | แสดงชื่อช่วงถัดไปและเวลาที่เหลือ |
| Offline | เพิ่ม JSON และโมดูลใหม่ใน Service Worker cache |

## วิธีอัปโหลด

1. แตกไฟล์ ZIP
2. เปิดโฟลเดอร์ `planet-age-cycle-v0.3.0-update-only`
3. อัปโหลดไฟล์และโฟลเดอร์ทั้งหมดไปที่ระดับบนสุดของ Repository
4. ยืนยันการแทนที่ไฟล์ชื่อเดิม
5. รอ GitHub Pages เผยแพร่
6. เปิด WebApp แล้วกดรีโหลดแบบไม่ใช้ Cache หรือปิด–เปิดใหม่

## ข้อจำกัดของ v0.3.0

- ยังเป็นโปรไฟล์เดียวใน `localStorage`; ระบบหลายโปรไฟล์ด้วย IndexedDB จะทำในขั้นถัดไป
- ยังไม่มี Timeline, Calendar View, บันทึกเหตุการณ์ และระบบแจ้งเตือนจริง
- ยังไม่แสดงสัญลักษณ์ดี–ไม่ดีบนทุกช่องของวงแหวน แต่แสดงสถานะในแผงรายละเอียดแล้ว
- `พระพุธแทรกพระราหู` ยังไม่มีข้อความต้นฉบับ จึงแสดงว่าไม่มีข้อมูล
- ภาษาอังกฤษยังไม่ทำ
