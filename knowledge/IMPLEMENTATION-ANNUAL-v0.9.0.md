# Implementation Note — Annual Forecast v0.9.0

## เป้าหมาย

เพิ่มหน้าผลประจำปีให้ระบบมหาทศา โดยรวม 4 ชั้นเวลา/คุณภาพ:

1. ดาวเสวยอายุหลักของมหาทศา
2. ดาวเสวยแทรกของมหาทศาที่ซ้อนอยู่ในปีชีวิตนั้น
3. ดาวภูมิทักษาประจำปี
4. ดาวอนุทักษา 8 ช่วงภายในปี

กาลโยคมหาภูติประจำปีทำงานเป็นนาฬิกาแยก และเปลี่ยนทันทีเมื่อผ่านวันเวลาเถลิงศก

## ฐานอายุภูมิทักษา

- ค่าเริ่มต้น `yang_age`
- `age_yang = completed_age + 1`
- มี `full_age` เป็นโหมดแยกที่ผู้ใช้เลือกได้

## อนุทักษา

ใช้ค่ากำลังจำเพาะคงที่จากองค์ความรู้ MAHA-TAKSA-08:

```text
1=20, 2=50, 3=26, 4=57, 7=33, 5=64, 8=40, 6=70
รวม = 360 วัน
```

ดาวแรกเป็นดาวภูมิอายุ แล้ววนตามลำดับ `[1,2,3,4,7,5,8,6]`

## การแสดงวันที่จริง

ต้นฉบับใช้ปีเชิงโหราศาสตร์ 360 วัน ซึ่งไม่เท่าปี Gregorian 365/366 วัน

v0.9.0 เลือกโหมด:

```text
gregorian_proportional_projection
```

โดยฉาย cumulative canonical days / 360 ลงบนช่วงจริงตั้งแต่วันเกิดครบรอบปีนี้ถึงวันเกิดครบรอบปีถัดไป

ข้อดี:

- ครอบคลุมปีชีวิตเต็มช่วง
- ไม่มี gap 5–6 วัน
- รักษาสัดส่วนกำลังจำเพาะของต้นฉบับ

ข้อจำกัด:

- วันที่จริงเป็นการฉายสัดส่วนสมัยใหม่ ไม่ใช่เลขคณิตเดือนละ 30 วันของต้นฉบับโดยตรง
- UI ต้องระบุว่าเป็นส่วนขยายสมัยใหม่

## Dynamic Kalayok

ทุกช่วงที่คร่อมวันเวลาเถลิงศกจะถูกแบ่งเป็น sub-segment โดยอัตโนมัติ:

```text
ก่อนเถลิงศก -> ใช้ จ.ศ. เดิม
ตั้งแต่เถลิงศก -> ใช้ จ.ศ. ใหม่
```

ดาวภูมิ/ดาวอนุทักษาไม่เปลี่ยนเพราะเถลิงศก แต่ตำแหน่งกาลโยคของดาวนั้นเปลี่ยนได้

## Rahu

ราหู (8) ไม่มีตำแหน่งในกาลโยคมหาภูติ 7 ดาว:

```text
quality = unknown
kalayoke_position = not_applicable
UI = สีเทา
```

ห้ามสร้างตำแหน่งกาลโยคสมมติให้ราหู

## Relationship Connector

เส้นจากมหาทศาเสวยหลักไปดาวเสวยแทรกใช้ความสัมพันธ์ของดาวคู่นั้น:

- supportive = เขียว
- conflicting = แดง
- mixed = ครึ่งเขียว/ครึ่งแดง
- ไม่มีแท็ก = เทา

การแสดง mixed รักษาหลักที่ว่าคู่ดาวหนึ่งคู่สามารถมีหลายแท็กพร้อมกัน
