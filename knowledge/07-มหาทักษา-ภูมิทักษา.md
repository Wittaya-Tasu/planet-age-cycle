## 1. นิยามและหลักใหญ่

**ภูมิทักษา** เป็นระบบพยากรณ์ช่วงชีวิตแบบปีต่อปี โดยดัดแปลงลำดับการเดินจากมหาทักษา ระบบนี้ใช้ดาว 8 ดวงเดินตามลำดับเดิม แต่กำหนดให้ดาวแต่ละดวงครองภูมิเท่ากันดวงละ **1 ปี**

ความแตกต่างจากดาวเสวยอายุแบบมหาทักษามีดังนี้

| ประเด็น | มหาทักษาเสวยอายุ | ภูมิทักษา |
|---|---|---|
| จำนวนดาว | 8 ดวง | 8 ดวง |
| ลำดับดาว | 1, 2, 3, 4, 7, 5, 8, 6 | 1, 2, 3, 4, 7, 5, 8, 6 |
| ระยะครองของดาว | ตามกำลังดาว รวมรอบละ 108 ปี | ดาวละ 1 ปี รวมรอบละ 8 ปี |
| จุดเริ่ม | ดาวประจำวันเกิด | ดาวประจำวันเกิด |
| หน้าที่ | บอกมหาทักษาที่เสวยและแทรกในช่วงยาวและช่วงย่อย | บอกดาวที่เป็นภูมิอายุของปีชีวิตนั้น |
| จุดเปลี่ยน | ตามวันสิ้นสุดของช่วงเสวยหรือแทรก | เปลี่ยนเมื่อครบรอบวันและเวลาเกิดแต่ละปี |

## 2. ลำดับดาวและผังอัฏฐจักร

### 2.1 ลำดับการเดิน

ดาวเดินแบบเวียนขวาหรือทักษิณาวัฏตามลำดับคงที่

```text
อาทิตย์ (1) -> จันทร์ (2) -> อังคาร (3) -> พุธ (4)
-> เสาร์ (7) -> พฤหัสบดี (5) -> ราหู (8) -> ศุกร์ (6)
-> กลับไปอาทิตย์ (1)
```

ค่าที่ใช้ในระบบ

```json
{
  "planetary_sequence": [1, 2, 3, 4, 7, 5, 8, 6],
  "movement": "clockwise",
  "years_per_planet": 1,
  "cycle_years": 8
}
```

### 2.2 ตำแหน่ง ทิศ และอุปมาตามต้นฉบับ

| ลำดับวงรอบ | ดาว | ทิศในผัง | ทิศปัจจุบัน | อุปมาตามต้นฉบับ |
|---:|---|---|---|---|
| 1 | อาทิตย์ (1) | อีสาน | ตะวันออกเฉียงเหนือ | พระยาภิเภก |
| 2 | จันทร์ (2) | บูรพา | ตะวันออก | พระราม |
| 3 | อังคาร (3) | อาคเนย์ | ตะวันออกเฉียงใต้ | พระยาพิมพิสาร |
| 4 | พุธ (4) | ทักษิณ | ใต้ | พระลักษณ์ |
| 5 | เสาร์ (7) | หรดี | ตะวันตกเฉียงใต้ | ทศกัณฐ์ |
| 6 | พฤหัสบดี (5) | ประจิม | ตะวันตก | นางสีดา |
| 7 | ราหู (8) | พายัพ | ตะวันตกเฉียงเหนือ | สดายุ |
| 8 | ศุกร์ (6) | อุดร | เหนือ | หนุมาน |

อุปมาเหล่านี้เป็นถ้อยคำเชิงวรรณคดีในตำรา ใช้เป็นภาพประกอบการอธิบาย ไม่ควรนำชื่อบุคคลในอุปมาไปสร้างคำพยากรณ์ตามตัวอักษรโดยไม่มีบริบทอื่น

## 3. ตำแหน่งทักษา 8 ตำแหน่ง

ตำแหน่งทักษาจัดเรียงตามลำดับวงรอบ โดยเริ่มตำแหน่ง **บริวาร** ที่ดาวประจำวันเกิด แล้วเดินตามลำดับดาวไปจนครบ 8 ตำแหน่ง

| ลำดับนับ | ตำแหน่ง | ความหมายหลักสำหรับระบบ |
|---:|---|---|
| 1 | บริวาร | บุตร คู่ครอง ผู้อยู่ในปกครอง ผู้ร่วมงาน ผู้ติดตาม และคนใกล้ตัว |
| 2 | อายุ | ความเป็นอยู่ สุขภาพ วิถีชีวิต ความต่อเนื่อง และอายุขัยตามความเชื่อของตำรา |
| 3 | เดช | อำนาจ บารมี อิทธิพล ความกล้า ชื่อเสียง และความเกรงขาม |
| 4 | ศรี | โชคลาภ สิริมงคล ความสำเร็จ เงินทอง และความสมบูรณ์ |
| 5 | มูละ | หลักฐาน ที่อยู่อาศัย ทรัพย์สินเดิม มรดก และรากฐานของชีวิต |
| 6 | อุตสาหะ | การงาน การลงมือทำ ความพากเพียร ความเหน็ดเหนื่อย และภารกิจ |
| 7 | มนตรี | ผู้ใหญ่ ครู อาจารย์ ที่ปรึกษา และผู้อุปถัมภ์เกื้อหนุน |
| 8 | กาลี | อุปสรรค ศัตรู ความเสื่อมเสีย ความอับโชค และสิ่งที่ควรระวัง |

เอกสารและระบบของโครงการกำหนดใช้คำว่า `กาลี` เป็นชื่อมาตรฐานต่อจากนี้

### 3.1 การวางตำแหน่งตามวันเกิด

ตัวอย่างผู้เกิดวันอาทิตย์

| ดาว | ตำแหน่งทักษา |
|---|---|
| อาทิตย์ (1) | บริวาร |
| จันทร์ (2) | อายุ |
| อังคาร (3) | เดช |
| พุธ (4) | ศรี |
| เสาร์ (7) | มูละ |
| พฤหัสบดี (5) | อุตสาหะ |
| ราหู (8) | มนตรี |
| ศุกร์ (6) | กาลี |

หากเกิดวันอื่น ให้เลื่อนจุดเริ่มต้นของตำแหน่งบริวารไปที่ดาวประจำวันเกิด แล้ววนตามลำดับเดิม

ตัวอย่างผู้เกิดวันเสาร์

```text
เสาร์ (7) = บริวาร
พฤหัสบดี (5) = อายุ
ราหู (8) = เดช
ศุกร์ (6) = ศรี
อาทิตย์ (1) = มูละ
จันทร์ (2) = อุตสาหะ
อังคาร (3) = มนตรี
พุธ (4) = กาลี
```

## 4. ฐานเวลาและฐานอายุ

### 4.1 ช่วงเวลาของภูมิทักษา

ดาวภูมิทักษาเปลี่ยนตาม **รอบวันและเวลาเกิด** ไม่ได้เปลี่ยนตามวันที่ขึ้นจุลศักราช

| อายุย่าง | ช่วงเวลา | ลำดับนับจากดาวเกิด |
|---:|---|---:|
| 1 | ตั้งแต่เกิดถึงก่อนครบรอบเกิด 1 ปี | 1 |
| 2 | ตั้งแต่ครบรอบเกิด 1 ปีถึงก่อนครบรอบเกิด 2 ปี | 2 |
| 3 | ตั้งแต่ครบรอบเกิด 2 ปีถึงก่อนครบรอบเกิด 3 ปี | 3 |
| ... | ... | ... |
| 8 | ปีชีวิตลำดับที่ 8 | 8 |
| 9 | เริ่มวงรอบใหม่ | 1 |

### 4.2 อายุโหรหรืออายุย่าง

ต้นฉบับใช้วิธี **อายุโหร** โดยยกตัวอย่างว่าอายุจริง 30 ปี 4 เดือน ให้กำหนดอายุคำนวณเป็น 31 ปี หลักที่เหมาะสำหรับระบบคือ

```text
age_yang = completed_years + 1
```

ดังนั้น

| อายุจริง ณ วันพยากรณ์ | อายุย่างที่ใช้คำนวณ |
|---|---:|
| 0 ปี 0 เดือน | 1 |
| 7 เดือน | 1 |
| 1 ปี 0 เดือน | 2 |
| 30 ปี 4 เดือน | 31 |

### 4.3 กรณีเลือกใช้อายุเต็ม

ข้อกำหนดของผู้จัดทำอนุญาตให้ระบบรองรับทั้งอายุย่างและอายุเต็ม แต่สองวิธีอาจให้ดาวคนละดวง จึงต้องถือเป็น **โหมดการคำนวณคนละแบบ** ไม่ใช่ค่าที่ใช้แทนกันได้โดยไม่ระบุ

| โหมด | ค่าคำนวณ | การใช้ |
|---|---|---|
| `yang_age` | อายุเต็ม + 1 | ค่าเริ่มต้นตามตัวอย่างอายุโหรในต้นฉบับ |
| `full_age` | อายุเต็ม | ใช้เฉพาะเมื่อผู้พยากรณ์เลือกหลักนี้อย่างชัดเจน และควรจำกัดค่าตั้งแต่ 1 ปีขึ้นไป |

กฎระบบ

1. ต้องบันทึก `age_basis` ทุกครั้ง
2. ต้องแสดงอายุเต็ม อายุย่าง และอายุที่นำไปคำนวณให้ผู้ใช้ตรวจสอบได้
3. ห้ามเริ่มคำนวณด้วยอายุย่างแล้วเปลี่ยนไปใช้อายุเต็มในขั้นพยากรณ์
4. หากต้องการเปรียบเทียบสองสำนัก ให้คำนวณเป็นสองผลลัพธ์แยกกัน

## 5. วิธีคำนวณดาวที่ตกภูมิ

### 5.1 ข้อมูลนำเข้า

| ตัวแปร | ความหมาย |
|---|---|
| `birth_datetime` | วันและเวลาเกิด |
| `birth_planet` | ดาวประจำวันเกิด |
| `target_datetime` | วันและเวลาที่ต้องการพยากรณ์ |
| `age_basis` | `yang_age` หรือ `full_age` |

หมายเหตุสำหรับโครงการ: หากใช้กฎวันพุธกลางวันและกลางคืน ให้กำหนดวันพุธกลางวันเป็นพุธ (4) และวันพุธกลางคืนเป็นราหู (8) ตามโมดูลแปลงวันเกิดของโครงการ โดยต้องใช้เกณฑ์เวลาเดียวกันทั้งระบบ

### 5.2 ขั้นตอนคำนวณ

1. คำนวณอายุเต็มจาก `birth_datetime` ถึง `target_datetime`
2. แปลงเป็นอายุคำนวณตาม `age_basis`
3. นำอายุคำนวณหารด้วย 8
4. ถ้าเศษเป็น 0 ให้ใช้ค่าการนับเท่ากับ 8
5. เริ่มนับ 1 ที่ดาวประจำวันเกิด
6. นับเวียนตามลำดับ `[1, 2, 3, 4, 7, 5, 8, 6]`
7. ดาวที่นับถึงคือ `annual_phumi_planet`
8. ลำดับนับ 1-8 ยังบอกตำแหน่งทักษา บริวาร-กาลี ของปีชีวิตนั้นด้วย

### 5.3 สูตร

ให้

```text
sequence = [1, 2, 3, 4, 7, 5, 8, 6]
birth_index = ตำแหน่งของ birth_planet ใน sequence
remainder = calculation_age mod 8
count = 8 ถ้า remainder = 0 มิฉะนั้นใช้ remainder
annual_index = (birth_index + count - 1) mod 8
annual_phumi_planet = sequence[annual_index]
annual_thaksa_position = thaksa_positions[count - 1]
```

โดย

```text
thaksa_positions = [
  "บริวาร", "อายุ", "เดช", "ศรี",
  "มูละ", "อุตสาหะ", "มนตรี", "กาลี"
]
```

### 5.4 ตัวอย่างตรวจสอบ

| วันเกิด | อายุคำนวณ | เศษหรือค่าการนับ | ดาวที่ตกภูมิ | ตำแหน่งทักษาของปีชีวิต |
|---|---:|---:|---|---|
| อาทิตย์ | 1 | 1 | อาทิตย์ (1) | บริวาร |
| อาทิตย์ | 2 | 2 | จันทร์ (2) | อายุ |
| อาทิตย์ | 8 | 8 | ศุกร์ (6) | กาลี |
| อาทิตย์ | 9 | 1 | อาทิตย์ (1) | บริวาร |
| เสาร์ | 1 | 1 | เสาร์ (7) | บริวาร |
| เสาร์ | 2 | 2 | พฤหัสบดี (5) | อายุ |
| เสาร์ | 8 | 8 | พุธ (4) | กาลี |

## 6. การประกอบกับกาลโยคมหาภูติประจำปี

### 6.1 ระบบมีนาฬิกาสองชุด

การพยากรณ์ภูมิทักษาต้องคำนวณเวลาแยกกันสองระบบ

| ระบบ | สิ่งที่หา | จุดเปลี่ยน |
|---|---|---|
| ภูมิทักษา | ดาวที่ตกภูมิของอายุ | วันและเวลาเกิดครบรอบแต่ละปี |
| กาลโยคมหาภูติ | คุณภาพประจำปีของดาว 1-7 | วันเริ่มจุลศักราชตามหลักปฏิทินใน `02-มหาทักษา-กาลโยคแบบมหาภูติ.md` |

ผลสำคัญคือ ภายในช่วงดาวภูมิทักษาดวงเดียวกัน ตำแหน่งกาลโยคอาจเปลี่ยนได้เมื่อข้ามวันเริ่มจุลศักราช ดังนั้นระบบต้องใช้ `target_datetime` คำนวณทั้งสองส่วนใหม่ทุกครั้ง

### 6.2 ขั้นตอนประกอบผล

1. หา `annual_phumi_planet` จากอายุและดาววันเกิด
2. หาจุลศักราชที่ใช้งาน ณ `target_datetime`
3. สร้างผังกาลโยคมหาภูติของจุลศักราชนั้น
4. ค้นหาว่า `annual_phumi_planet` อยู่ตำแหน่งใดในกาลโยค
5. ใช้ตำแหน่งกาลโยคกำหนดแนวคุณหรือโทษ
6. ใช้ความหมายของดาวและตำแหน่งทักษาขยายว่าเหตุการณ์เกี่ยวกับเรื่องใด
7. ใช้ความสัมพันธ์ของดาวจากโมดูลคู่ดาวเป็นเงื่อนไขเสริมหรือลดผล

### 6.3 ลำดับความร้ายแรงตามต้นฉบับ

| ระดับ | ตำแหน่งกาลโยค | แนวผล |
|---:|---|---|
| 1 | โลกาวินาศ | โทษร้ายแรงที่สุด |
| 2 | มรณะ | โทษรองลงมา |
| 3 | อริ | อุปสรรค ศัตรู และความขัดแย้ง |

สำหรับตำแหน่งอื่น

| ตำแหน่งกาลโยค | หลักใช้ในภูมิทักษา |
|---|---|
| อธิบดี | แม้มีลาภอาจเป็นลาภที่พอกพูนภาระหรือทุกขลาภ ต้นฉบับเรียก “หินะลาภ” |
| ขุมทรัพย์ | ใช้แนวทรัพย์ ผลประโยชน์ และโอกาสทางวัตถุ |
| ราชาโชค | ใช้แนวโชค ความสำเร็จ หรือการได้รับการยอมรับ |
| ธงชัย | ใช้แนวชัยชนะ ความสำเร็จ และความราบรื่น |

ตำแหน่งกาลโยคไม่ควรถูกใช้เดี่ยวๆ ต้องอ่านร่วมกับดาวที่ตกภูมิ ตำแหน่งทักษา ความหมายดาว และความสัมพันธ์ของดาว

### 6.4 ข้อยกเว้นของราหู

กาลโยคมหาภูติในโมดูลนี้ใช้ดาว 7 ดวง คืออาทิตย์ถึงเสาร์ ราหูจึงไม่มีตำแหน่งโลกาวินาศ อริ มรณะ หรือฝ่ายดีในผังกาลโยคประจำปี

เมื่อตกภูมิราหู ต้นฉบับให้อุปมาเป็น **สดายุ** และเตือนว่า

- ไม่ควรเข้าไปยุ่งเกี่ยวกับเรื่องของผู้อื่นโดยไม่จำเป็น
- การช่วยเหลืออาจย้อนกลับมาเป็นโทษหรือทำคุณไม่ขึ้น
- ความเดือดร้อนอาจเกิดจากเรื่องที่ไม่ได้เป็นหน้าที่ของตน

ระบบต้องบันทึกเป็น `rahu_exception` และห้ามสร้างตำแหน่งกาลโยคปลอมให้ราหู

## 7. คำแปลเมื่อดาวที่ตกภูมิเป็นโลกาวินาศ

หลักนี้ใช้เมื่อ

1. คำนวณได้ว่าปัจจุบันตกภูมิดาวดวงหนึ่ง และ
2. ดาวดวงนั้นอยู่ตำแหน่งโลกาวินาศในกาลโยคมหาภูติของวันพยากรณ์

| ดาวที่ตกภูมิ | คำแปลตามต้นฉบับ | ถ้อยคำแนะนำสำหรับระบบ |
|---|---|---|
| อาทิตย์ (1) | ผิดใจกับผู้ใหญ่ ร้อนใจเรื่องที่อยู่อาศัย มีอุปสรรคด้านงานและอาชีพ | ระวังความสัมพันธ์กับผู้ใหญ่ ผู้บังคับบัญชา งาน ตำแหน่ง และที่อยู่อาศัย |
| จันทร์ (2) | ระบบการเงินเสียหายหรือเก็บเงินไม่อยู่ เดือดร้อนจากหญิงอายุมากกว่า สุขภาพไม่ดี | ระวังสภาพคล่อง รายจ่าย ความสัมพันธ์กับสตรีอาวุโส และดูแลสุขภาพตามความเหมาะสม |
| อังคาร (3) | ชะตาสตรีเดือดร้อนจากสามีหรือเพศตรงข้าม ชะตาบุรุษยุ่งยากเพราะลูกน้อง | ในการใช้ภาษาสมัยใหม่ ให้ตรวจบริบทคู่ครอง เพศตรงข้าม ลูกน้อง หรือผู้ใต้บังคับบัญชา โดยไม่เหมารวมจากเพศเพียงอย่างเดียว |
| พุธ (4) | ร้อนใจเพราะบุตรหลาน มีอุปสรรคด้านอาชีพ และสุขภาพทรุดโทรม | ระวังเรื่องบุตรหลาน การสื่อสาร งานอาชีพ และสุขภาพ แต่ห้ามใช้เป็นคำวินิจฉัยโรค |
| เสาร์ (7) | คนชั้นล่างหรือบริวารนำความเดือดร้อน บริวารเป็นโทษ และอบายมุขทำให้เสื่อมเสีย | ปรับคำโบราณเป็นลูกน้อง ผู้ช่วย ผู้ให้บริการ หรือคนในความรับผิดชอบ และเตือนเรื่องพฤติกรรมเสี่ยงหรืออบายมุข |
| พฤหัสบดี (5) | อับโชค ไม่ควรทำการใหญ่ เจ้านายมองในแง่ร้าย และมิตรกลับก่อทุกข์โทษ | ชะลอการขยายงานหรือการตัดสินใจใหญ่ ตรวจความสัมพันธ์กับผู้ใหญ่ ที่ปรึกษา และมิตร |
| ศุกร์ (6) | ชะตาบุรุษเดือดร้อนจากภรรยาหรือเพศตรงข้าม ชะตาสตรีเดือดร้อนด้านการเงิน | ตรวจบริบทคู่ครอง ความรัก ความสัมพันธ์ การเงิน และทรัพย์สิน โดยใช้ถ้อยคำเชิงแนวโน้ม |

ราหูไม่อยู่ในตารางนี้ เพราะไม่มีตำแหน่งโลกาวินาศในกาลโยคมหาภูติ 7 ดาว ให้ใช้กฎ `rahu_exception` แยกต่างหาก

## 8. ตัวอย่างการประกอบผลในต้นฉบับ

ต้นฉบับยกผังกาลโยคของ **จุลศักราช 1326** เพื่อแสดงวิธีนำดาวที่ตกภูมิไปเทียบกับตำแหน่งประจำปี ตัวอย่างเหล่านี้เป็นกรณีของปีนั้น ไม่ใช่ตำแหน่งถาวรของดาว

| ดาวที่ตกภูมิ | ตำแหน่งในตัวอย่าง จ.ศ. 1326 | แนวอธิบายในต้นฉบับ |
|---|---|---|
| อาทิตย์ (1) | ราชาโชค | มีโอกาสได้รับความโปรดปราน การยอมรับ หรือคุณจากผู้มีอำนาจ |
| จันทร์ (2) | ธงชัย | มีชัย ความสำเร็จ ความรุ่งเรือง และความเป็นสิริมงคล |
| อังคาร (3) | โลกาวินาศ | บริวารหรือคู่ครองอาจนำความเดือดร้อน และต้องระวังความขัดแย้ง |
| พุธ (4) | อริ | ระวังศัตรู การพูดที่ก่อโทษ และความยุ่งยาก แต่บริบทดาวอื่นอาจทำให้เกิดการเดินทาง |
| เสาร์ (7) | อธิบดี | อาจมีเกียรติหรือตำแหน่ง แต่ต้องแลกด้วยภาระ ความเหน็ดเหนื่อย หรือปัญหางาน |
| พฤหัสบดี (5) | ขุมทรัพย์ | มีโอกาสด้านโชคลาภ ผู้สนับสนุน มิตร และทรัพย์สิน |
| ศุกร์ (6) | มรณะ | ระวังความสัมพันธ์ ความขัดแย้ง และการสูญเสียที่เกี่ยวกับเรื่องของศุกร์ |
| ราหู (8) | ไม่มีตำแหน่ง | ใช้กฎสดายุและคำเตือนเรื่องการเข้าไปยุ่งกับเรื่องผู้อื่น |

ห้ามนำตารางนี้ไปตั้งค่าถาวร เช่น ห้ามกำหนดว่าอาทิตย์เป็นราชาโชคทุกปี ต้องคำนวณกาลโยคใหม่ตามจุลศักราชของวันพยากรณ์เสมอ

## 9. การขยายคำพยากรณ์ด้วยองค์ความรู้อื่น

เมื่อทราบดาวที่ตกภูมิและตำแหน่งกาลโยคแล้ว ให้ขยายคำพยากรณ์ตามลำดับดังนี้

| ชั้นข้อมูล | คำถามที่ตอบ | แหล่งองค์ความรู้ |
|---|---|---|
| ดาวที่ตกภูมิ | ปีชีวิตนี้อยู่ภายใต้ดาวใด | ไฟล์นี้ |
| ตำแหน่งทักษา | เรื่องในรอบชีวิตอยู่ที่บริวาร อายุ เดช ศรี ฯลฯ | ไฟล์นี้ |
| ตำแหน่งกาลโยค | ดาวให้คุณ ให้โทษ หรือมีเงื่อนไขระดับใด | หลักการที่ 2 |
| ความหมายของดาว | เกี่ยวกับใคร เรื่องใด สถานที่ ทิศ สี ธาตุ หรือวัตถุใด | หลักการที่ 6 |
| ความสัมพันธ์ของดาว | มีดาวคู่มิตร คู่ศัตรู คู่ธาตุ หรือคู่สมพลประกอบหรือไม่ | หลักการที่ 5 |

ต้นฉบับยกตัวอย่างว่า เมื่อตกภูมิพฤหัสบดีและต้องการถามรายละเอียดเพิ่มเติม อาจใช้รูปร่าง บุคคล ทิศ และสินค้าในความหมายของพฤหัสบดี รวมถึงพิจารณาดาวคู่มิตรประกอบ หลักที่ได้คือ

1. เลือกเฉพาะมิติที่ตรงกับคำถาม
2. ใช้ดาวคู่สัมพันธ์เป็นข้อมูลประกอบ ไม่ใช้แทนดาวที่ตกภูมิ
3. ห้ามเทสี รส รูปร่าง โรค ทิศ และอาชีพทุกอย่างลงในคำพยากรณ์ครั้งเดียว
4. ห้ามใช้ลักษณะดาวระบุตัวบุคคลจริงอย่างเด็ดขาด

## 10. ลำดับประมวลผลสำหรับระบบ

```text
input:
  birth_datetime
  birth_planet
  target_datetime
  age_basis
  query_context

1. คำนวณ completed_age และ age_yang
2. เลือก calculation_age ตาม age_basis
3. หา count จาก calculation_age mod 8
4. หา annual_phumi_planet จากลำดับดาวและ birth_planet
5. หา annual_thaksa_position จาก count
6. ถ้า annual_phumi_planet = 8:
     ใช้ rahu_exception
   มิฉะนั้น:
     หา chula_sakarat ณ target_datetime
     สร้าง annual_kalayoke_map
     หา kalayoke_position ของ annual_phumi_planet
7. ประเมิน benefit_harm_level
8. ถ้า kalayoke_position = โลกาวินาศ:
     โหลดคำแปลโลกาวินาศเฉพาะดาว
9. โหลดความหมายดาวเฉพาะมิติที่ตรงกับ query_context
10. โหลดความสัมพันธ์ของดาวเมื่อมีดาวประกอบ
11. สร้างคำพยากรณ์เชิงแนวโน้มพร้อมแสดงฐานอายุและช่วงวันที่
```

## 12. ข้อทดสอบความถูกต้อง

| ลำดับ | กรณีทดสอบ | ผลที่ต้องได้ |
|---:|---|---|
| 1 | ตรวจลำดับดาว | ต้องได้ `[1, 2, 3, 4, 7, 5, 8, 6]` |
| 2 | เกิดวันอาทิตย์ อายุย่าง 1 | ตกภูมิอาทิตย์และตำแหน่งบริวาร |
| 3 | เกิดวันอาทิตย์ อายุย่าง 8 | ตกภูมิศุกร์และตำแหน่งกาลี |
| 4 | เกิดวันอาทิตย์ อายุย่าง 9 | วนกลับมาตกภูมิอาทิตย์ |
| 5 | เกิดวันเสาร์ อายุย่าง 2 | ตกภูมิพฤหัสบดีและตำแหน่งอายุ |

| 8 | เลือกโหมด `full_age` | ต้องแสดงฐานอายุชัดเจนและไม่ปะปนผลจาก `yang_age` |
| 9 | ดาวภูมิทักษาอยู่โลกาวินาศ | harm_rank ต้องเท่ากับ 1 |
| 10 | ดาวภูมิทักษาอยู่มรณะ | harm_rank ต้องเท่ากับ 2 |
| 11 | ดาวภูมิทักษาอยู่อริ | harm_rank ต้องเท่ากับ 3 |

| 13 | ข้ามวันเริ่มจุลศักราชแต่ยังไม่ถึงวันเกิด | ดาวภูมิทักษาคงเดิม แต่ต้องคำนวณตำแหน่งกาลโยคใหม่ |
| 14 | ข้ามวันเกิดแต่ยังอยู่จุลศักราชเดิม | ดาวภูมิทักษาเปลี่ยน แต่ผังกาลโยคยังใช้จุลศักราชเดิม |
| 15 | ใช้ตัวอย่าง จ.ศ. 1326 | ต้องแสดงว่าเป็นตัวอย่างเฉพาะปี ห้ามเก็บตำแหน่งดาวเป็นค่าถาวร |
| 16 | ขอเนื้อหาอนุทักษาพยากรณ์ | ต้องไม่ดึงกฎจากไฟล์นี้ และส่งต่อไปองค์ความรู้ลำดับถัดไป |

## 13. จุดตรวจพบและข้อสรุปที่ใช้

| ประเด็น | ผลการตรวจเทียบและข้อกำหนด |
|---|---|
| ชื่อระบบ | ต้นฉบับใช้ทั้ง “ทักษาพยากรณ์” และ “ภูมิพยากรณ์” ส่วนโครงการใช้ชื่อ “ภูมิทักษา” จึงเก็บเป็นชื่อหลักพร้อมชื่อเรียกแทน |
| ระยะเวลาของดาว | ต้นฉบับกำหนดภูมิละ 1 ปีเท่ากัน ไม่ใช้กำลังดาวแบบรอบ 108 ปี |
| จุดเริ่มนับ | เริ่มนับ 1 ที่ดาวประจำวันเกิด |
| ฐานอายุ | ต้นฉบับยกอายุโหรหรืออายุย่างเป็นวิธีหลัก โหมดอายุเต็มเป็นตัวเลือกของโครงการและต้องระบุให้ชัด |
| การหารด้วย 8 | เศษ 0 ต้องแปลงเป็นค่าการนับ 8 |
| การเปลี่ยนภูมิ | เปลี่ยนตามรอบวันและเวลาเกิด ไม่ใช่วันขึ้นจุลศักราช |
| การเปลี่ยนกาลโยค | คำนวณแยกตามวันเริ่มจุลศักราชจากหลักการที่ 2 |
| ระดับโทษ | โลกาวินาศร้ายชั้น 1 มรณะชั้น 2 และอริชั้น 3 |
| อธิบดี | ไม่ควรตีความเป็นดีล้วน ต้นฉบับเตือนเรื่องทุกขลาภหรือหินะลาภ |
| ราหู | ไม่มีตำแหน่งในกาลโยค 7 ดาว ต้องใช้กฎสดายุแยกต่างหาก |
| ภาษาด้านชนชั้นและเพศ | เก็บถ้อยคำตามต้นฉบับเป็นข้อมูลแหล่งที่มา แต่ใช้ถ้อยคำกลางและตรวจบริบทจริงในการแสดงผล |
| อนุทักษาพยากรณ์ | เริ่มในหน้าหนังสือ 65 และถูกตัดออกทั้งหมดตามขอบเขตงาน |

## 14. สรุปหลักสั้นๆ

> ภูมิทักษาใช้ดาว 8 ดวงเดินตามลำดับ 1 -> 2 -> 3 -> 4 -> 7 -> 5 -> 8 -> 6 เริ่มจากดาววันเกิดและให้ดาวละ 1 ปี หาอายุคำนวณแล้วใช้เศษจากการหาร 8 เพื่อนับหาดาวที่ตกภูมิ จากนั้นนำดาวนั้นไปเทียบกับกาลโยคมหาภูติของวันพยากรณ์เพื่อกำหนดคุณหรือโทษ โดยโลกาวินาศร้ายที่สุด รองลงมาคือมรณะและอริ ส่วนราหูไม่มีตำแหน่งในกาลโยค 7 ดาวและต้องใช้กฎสดายุแยกต่างหาก การคำนวณต้องแยกนาฬิกาวันเกิดออกจากนาฬิกาจุลศักราช และต้องระบุฐานอายุย่างหรืออายุเต็มให้ชัดเจนเสมอ
