# พระเคราะห์เสวยอายุ

WebApp สำหรับคำนวณพระเคราะห์เสวยอายุ แสดงวงล้อ 108 ปี คำพยากรณ์ และ Timeline แบบแยกพระเคราะห์หลักเป็นรายแถว

## เวอร์ชันปัจจุบัน

`v0.7.0`

## ความสามารถหลัก

| ฟังก์ชัน | รายละเอียด |
|---|---|
| วงล้อเสวยอายุ | 8 แถบหลักและ 64 แถบย่อยตามสัดส่วนเวลา |
| หมุนตามวันเกิด | พระเคราะห์ประจำวันเกิดอยู่ที่ตำแหน่ง 12 นาฬิกา |
| สัญลักษณ์ดี–ไม่ดี | แสดงล่วงหน้าครบทุกช่วงตามความสัมพันธ์ของวันเกิด |
| Timeline รายแถว | แสดงหนึ่งพระเคราะห์หลักต่อหนึ่งแถว เริ่มจากดาวเกิด |
| ช่วงอายุ | แสดงอายุเริ่มต้นและสิ้นสุดของแต่ละแถบหลัก |
| รายละเอียด | คลิกวงล้อหรือ Timeline เพื่ออ่านช่วงเวลาและคำพยากรณ์ |
| บันทึกภาพ PNG | รองรับทั้งวงล้อและ Timeline |
| PWA | ใช้งานออฟไลน์และเพิ่มไปยังหน้าจอโฮมได้ |

## สัญลักษณ์ความสัมพันธ์

- `✓` สีเขียว หมายถึงดาวที่มีความสัมพันธ์ดีตามวันเกิด
- `!` สีแดง หมายถึงดาวที่มีความสัมพันธ์ไม่ดีตามวันเกิด
- ระบบแสดงเครื่องหมายทั้งแถบหลักและแถบย่อยทุกตำแหน่งที่ตรงกับตาราง
- ดาวที่ไม่มีข้อมูลความสัมพันธ์จะไม่แสดงเครื่องหมาย

## Timeline แบบใหม่

Timeline v0.7.0 แยกเป็น 8 แถว:

- แถวแรกคือพระเคราะห์ประจำวันเกิด
- แต่ละแถวมีแถบหลักด้านบนและแถบย่อยด้านล่าง
- ความยาวของแต่ละแถวสะท้อนจำนวนปีของพระเคราะห์หลัก
- แถบย่อยแต่ละช่องกว้างตามสัดส่วนเวลาจริง
- ด้านขวาแสดงช่วงอายุเริ่มต้น–สิ้นสุด
- ช่วงปัจจุบันมีเส้นและลูกศรระบุตำแหน่ง
