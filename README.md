# มหาทศา

WebApp โหราศาสตร์ไทยสำหรับแสดง **ดาวเสวยอายุ 108 ปี**, **ดาวแทรก**, **กาลโยคมหาภูติกำเนิด** และ **ความสัมพันธ์ของดาว**

**Current version:** `v0.8.1`

## ฟังก์ชันหลัก

- รับ วันเกิด / วันที่ / เดือน / ปี พ.ศ. / เวลาเกิด
- เวลาเกิดไม่ทราบเก็บเป็น `null`
- วันที่คำนวณอายุ default เป็นวันปัจจุบันและเปลี่ยนได้
- คำนวณจุลศักราชกำเนิดจากวันเวลาเถลิงศก
- คำนวณกาลโยคมหาภูติกำเนิด 7 ตำแหน่ง
- ดาวเสวยอายุ 8 ดวง รอบ 108 ปี
- พุธกลางคืนยังเริ่มดาวเสวยอายุด้วยราหู (8)
- กาลโยคมหาภูติใช้เฉพาะดาว 1–7 ไม่มีราหู
- มุมมองวงกลมและ Timeline
- คลิกแถบหลักเพื่อขยาย Timeline ดาวแทรกภายในช่วงนั้น
- ความสัมพันธ์ดาว 6 ประเภท
- PNG export ทั้ง Wheel และ Timeline
- PWA / Offline
- ใช้ฟอนต์ **Sarabun** แบบ self-hosted ทั้งระบบ

## ลำดับดาวเสวยอายุ

```text
1 → 2 → 3 → 4 → 7 → 5 → 8 → 6
```

รวมกำลังดาว 108 ปี

## กาลโยคมหาภูติ

```text
โลกาวินาศ → อริ → ขุมทรัพย์ → มรณะ → อธิบดี → ราชาโชค → ธงชัย
```

ใช้ดาว 1–7 เท่านั้น ราหู (8) ไม่มีตำแหน่งในชั้นกาลโยคมหาภูติ

## การคำนวณจุลศักราชใน v0.8.1

ระบบไม่ใช้กฎลัดวันที่คงที่ และไม่ต้องดาวน์โหลดตารางวันเถลิงศกทุกปี

ใช้เกณฑ์สุริยยาตร์:

```text
CS = CE - 638
JD เถลิงศก = ((292207 × CS) + 373) / 800 + 1954167.5
```

WebApp คำนวณ boundary เองแบบ local/offline แล้วใช้ MyHora เป็นชุดสอบทานเท่านั้น

### Time convention

ผลในแหล่งโหราศาสตร์แบบเก่าอาจแสดงเป็นเวลาท้องถิ่นกรุงเทพฯ `UTC+06:42` แต่เวลาเกิดที่ผู้ใช้กรอกในระบบเป็นเวลามาตรฐานประเทศไทย `UTC+07:00` ดังนั้นก่อนเปรียบเทียบ ระบบบวก 18 นาทีให้ clock time ของ boundary

ตัวอย่าง:

```text
พ.ศ. 2527: 15 เม.ย. 17:51:00 (UTC+06:42)
            → 15 เม.ย. 18:09:00 (UTC+07:00)

พ.ศ. 2569: 16 เม.ย. 14:40:12 (UTC+06:42)
            → 16 เม.ย. 14:58:12 (UTC+07:00)
```

หากไม่ทราบเวลาเกิดและเกิดตรงวันเถลิงศก ระบบคืนค่า `ambiguous` สองค่าและไม่สมมติว่าเกิดเวลา 00:00 น.
