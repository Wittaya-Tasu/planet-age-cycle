# มหาทศา

WebApp โหราศาสตร์ไทยสำหรับแสดง **มหาทศา 108 ปี**, **ดาวแทรก**, **กาลโยคมหาภูติ**, **ภูมิทักษา**, **อนุทักษาพยากรณ์** และ **ความสัมพันธ์ของดาว**

**Current version:** `v0.9.4`

## 3 หน้าหลัก

1. **ข้อมูลเจ้าชะตา** — วันเกิด วันที่ เดือน ปี พ.ศ. เวลาเกิด และวันที่ต้องการคำนวณ (ใช้ช่อง พ.ศ.)
2. **มหาทศา** — วงกลม 108 ปี / Timeline / กาลโยคมหาภูติกำเนิด
3. **ผลประจำปี** — มองปีชีวิตหนึ่งปีแบบหลายชั้น ตั้งแต่มหาทศาถึงอนุทักษา

## หน้าผลประจำปี v0.9.3

แสดงจากซ้ายไปขวา:

- **ดาวเสวยอายุหลัก** — ใช้ตำแหน่งกาลโยคมหาภูติกำเนิด
- **ดาวเสวยแทรกในปีนั้น** — แบ่งตามเวลาที่ซ้อนทับกับปีชีวิต และใช้กาลโยคมหาภูติประจำปี
- **ภูมิทักษา** — ดาวภูมิอายุประจำปี พร้อมตำแหน่งบริวาร–กาลี
- **อนุทักษา** — 8 ช่วงภายในปี พร้อมวันที่เริ่ม–สิ้นสุด

ระบบวาดรอยต่อเถลิงศก/จุลศักราชลงบนแผนภาพ และเปลี่ยนสถานะกาลโยคของดาวทันทีเมื่อข้ามรอยต่อ แม้ดาวประจำช่วงจะยังเป็นดวงเดิม

### ปรับ UI ใน v0.9.2

- ตัวเลือกฐานอายุใช้คำสั้น `อายุย่าง` และ `อายุเต็ม`
- เลขอายุในแท่งเสวยหลักเปลี่ยนตามฐานอายุที่ผู้ใช้เลือกจริง
- แท่ง 1–4 กว้างเท่ากันเพื่อให้ภาพสมดุลขึ้น
- แท่งภูมิทักษา ถ้าเป็นราหู (8) จะไม่แสดงคำว่า `นอกมหาภูติ` ภายในแท่ง
- แท่งอนุทักษาเอาเส้นประรอยต่อวันออก และวางข้อความวันชิดขอบรอยต่อแต่ละช่วง
- เพิ่มแท่งที่ 5 เป็นแถบ `12 เดือนปกติ` เพื่อเทียบกับ 8 ช่วงอนุทักษา

### การเทียบแกนเวลาใน v0.9.3

แท่ง `อนุทักษา` และ `เดือนปฏิทิน` ใช้แกนเวลาเดียวกันตลอดปีชีวิต วันเวลาเดียวกันจึงอยู่ในระดับแนวนอนเดียวกันเสมอ โดยเดือนปฏิทินตัดที่วันที่ 1 เวลา 00:00 ของแต่ละเดือนจริง เดือนแรกและเดือนสุดท้ายอาจเป็นช่วงบางส่วนเมื่อปีชีวิตเริ่ม/จบกลางเดือน

### ปรับ UI ใน v0.9.4

- แท่ง `เดือนปฏิทิน` ใช้ชื่อเดือน + ปี พ.ศ. 2 หลักในบรรทัดเดียว เช่น `พ.ค.69`
- เดือนที่ตรงกับเวลาปัจจุบันจริงจะใช้พื้นเทาเข้มขึ้นเพื่อช่วยชี้ตำแหน่งเวลา
- current-month highlight จะไม่แสดงเมื่อเวลาปัจจุบันอยู่นอกช่วงปีชีวิตที่เปิดดู

## ภูมิทักษา

- ดาว 8 ดวงเดินตามลำดับ `1 → 2 → 3 → 4 → 7 → 5 → 8 → 6`
- ดาวละ 1 ปี รอบ 8 ปี
- เริ่มที่ดาวประจำวันเกิด
- ค่าเริ่มต้นใช้อายุย่าง (`อายุเต็ม + 1`) ตามตัวอย่างต้นฉบับ
- ผู้ใช้เลือกโหมดอายุเต็มได้โดยชัดเจน

## อนุทักษา

กำลังจำเพาะตามตำรา:

| ดาว | วัน canonical |
|---:|---:|
| 1 | 20 |
| 2 | 50 |
| 3 | 26 |
| 4 | 57 |
| 7 | 33 |
| 5 | 64 |
| 8 | 40 |
| 6 | 70 |
| **รวม** | **360** |

เพื่อให้หน้า WebApp แสดงวันที่จริงครอบคลุมวันเกิดปีนี้ถึงวันเกิดปีถัดไปโดยไม่มีช่องว่าง ระบบใช้ **Gregorian proportional projection**: รักษาสัดส่วน canonical 360 วัน แต่ฉายลงบนช่วงปีปฏิทินจริง 365/366 วัน นโยบายนี้เป็นส่วนขยายสมัยใหม่และถูกระบุใน UI

## กาลโยคมหาภูติ

ใช้ดาว 1–7 เท่านั้น:

`โลกาวินาศ → อริ → ขุมทรัพย์ → มรณะ → อธิบดี → ราชาโชค → ธงชัย`

ราหู (8) ไม่มีตำแหน่งกาลโยคมหาภูติ จึงแสดงสีเทา/นอกมหาภูติ

## ความสัมพันธ์ดาว

รองรับ 6 ประเภทและหลายแท็กต่อคู่ดาว ระบบ annual view สรุป polarity สำหรับจุดเชื่อม:

- supportive = เขียว
- conflicting = แดง
- mixed = ครึ่งเขียว/ครึ่งแดง
- ไม่มีข้อมูล = เทา
