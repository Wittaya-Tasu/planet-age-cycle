# มหาทศา

WebApp โหราศาสตร์ไทยสำหรับแสดง **ดาวเสวยอายุ 108 ปี**, **ดาวแทรก**, **กาลโยคมหาภูติกำเนิด** และ **ความสัมพันธ์ของดาว**

**Current version:** `v0.8.0`

## สิ่งที่เปลี่ยนจากระบบพระเคราะห์เสวยอายุ v0.7.1

v0.8.0 เป็นการปรับโครงสร้างครั้งใหญ่จาก “ระบบดาวเสวยอายุ” ไปเป็น “มหาทศา” โดยยังรักษา engine ดาวเสวยอายุเดิม แต่เพิ่มกาลโยคมหาภูติและความสัมพันธ์ของดาวเป็นชั้นข้อมูลใหม่

### ฟังก์ชันหลัก

- รับ วันเกิด / วันที่ / เดือน / ปี พ.ศ. / เวลาเกิด
- เวลาเกิดสามารถเป็น `null` ได้จริงเมื่อไม่ทราบเวลา
- วันที่คำนวณอายุเริ่มต้นเป็นวันปัจจุบันและเปลี่ยนได้
- หาจุลศักราชกำเนิดโดยใช้วันเวลาเถลิงศกเมื่อมีข้อมูลรอยต่อที่ตรวจสอบแล้ว
- คำนวณกาลโยคมหาภูติกำเนิด 7 ตำแหน่ง
- ระบบดาวเสวยอายุ 8 ดวง รอบ 108 ปีคงเดิม
- พุธกลางคืนยังเริ่มดาวเสวยอายุด้วยราหู (8)
- กาลโยคมหาภูติใช้เฉพาะดาว 1–7 ไม่มีราหู
- มุมมองวงกลมและ Timeline
- คลิกแถบหลักเพื่อขยาย Timeline ดาวแทรกภายในช่วงนั้น
- แสดงสถานะมหาภูติด้วยสีของแถบ
- แสดงความสัมพันธ์คู่มิตร/คู่ศัตรูเป็น badge รอบตัวเลข
- ความสัมพันธ์ประเภทอื่นแสดงด้วยเส้นประและชื่อความสัมพันธ์ในวงกลม และ chip ใน Timeline
- ตัดคำพยากรณ์เดิมออกจาก UI
- บันทึกภาพ PNG ได้ทั้งวงกลมและ Timeline
- PWA / Offline

## ลำดับดาวเสวยอายุ

```text
1 → 2 → 3 → 4 → 7 → 5 → 8 → 6
```

กำลังดาวรวม 108 ปี

## กาลโยคมหาภูติ

ลำดับตำแหน่ง:

```text
โลกาวินาศ → อริ → ขุมทรัพย์ → มรณะ → อธิบดี → ราชาโชค → ธงชัย
```

ใช้ดาว 1–7 เท่านั้น

### กลุ่มสีใน UI v0.8.0

- โลกาวินาศ: แดงเข้ม ตัวอักษรขาว
- อริ / มรณะ: แดงอ่อน ตัวอักษรแดงเข้ม
- ขุมทรัพย์ / อธิบดี / ราชาโชค / ธงชัย: เขียวอ่อน ตัวอักษรเขียวเข้ม
- ราหู (8): เทาอ่อน เพราะไม่มีตำแหน่งในมหาภูติชุดนี้

> หมายเหตุ: การจัดอธิบดีเป็นกลุ่มบวกใน UI v0.8.0 เป็นข้อกำหนดของระบบสำหรับชั้นสีภาพรวม ส่วนการตีความเชิงลึกในองค์ความรู้ MAHA-TAKSA-04 ยังมีเงื่อนไขเพิ่มเติม และยังไม่ถูกนำมาแสดงในรุ่นนี้

## ความสัมพันธ์ของดาว

รองรับ 6 ประเภท:

- คู่มิตร
- คู่ศัตรู
- คู่ธาตุ
- คู่ศัตรูธาตุ
- คู่สมพล
- คู่ศัตรูสมพล

หนึ่งคู่สามารถมีหลาย tag พร้อมกันได้

## การคำนวณจุลศักราช

ระบบไม่ใช้กฎลัด “16 เมษายน 06:00 น.”

v0.8.0 มีสถาปัตยกรรม annual boundary dataset และมี boundary ที่ตรวจสอบจากองค์ความรู้ที่แนบแล้วสำหรับ ค.ศ. 1984:

```text
15 เมษายน 1984 เวลา 17:51 น. (Asia/Bangkok)
```

สำหรับปีอื่น:

- มกราคม–มีนาคม: ใช้ จ.ศ. ของปีก่อน candidate
- พฤษภาคม–ธันวาคม: ใช้ candidate ของปีนั้น
- เมษายนที่ยังไม่มี boundary ตรวจสอบ: คืนค่า `ambiguous` แทนการเดา

นี่เป็น deliberate safety rule เพราะเอกสารองค์ความรู้ไม่ได้ให้สูตรสุริยยาตร์ฉบับเต็มหรือ annual boundary table ครบทุกปี
