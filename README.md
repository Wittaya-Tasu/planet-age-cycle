# Planet Age Cycle

WebApp สำหรับคำนวณพระเคราะห์เสวยอายุ แสดงวงล้อ 108 ปี และ Timeline แนวนอนตามสัดส่วนเวลาจริง

## เวอร์ชันปัจจุบัน

`v0.6.0`

## ความสามารถหลัก

| ฟังก์ชัน | รายละเอียด |
|---|---|
| วงล้อเสวยอายุ | แสดง 8 แถบหลักและ 64 แถบย่อย |
| หมุนตามวันเกิด | พระเคราะห์ประจำวันเกิดอยู่ที่ตำแหน่ง 12 นาฬิกา |
| Timeline แนวนอน | แสดงลำดับช่วงชีวิตตลอด 108 ปีแบบเลื่อนแนวนอน |
| สัญลักษณ์ดี–ไม่ดี | แสดงล่วงหน้าทั้งวงล้อและ Timeline ตามวันเกิด |
| รายละเอียดช่วงชีวิต | เริ่ม–สิ้นสุด ช่วงถัดไป และคำพยากรณ์ |
| บันทึกภาพ PNG | บันทึกได้ทั้งมุมมองวงล้อและ Timeline |
| PWA | ใช้งานออฟไลน์และติดตั้งบนหน้าจอหลักได้ |

## แนวทางการแสดงสัญลักษณ์

- แถบหลัก: แสดงสัญลักษณ์ไว้ด้านในของวงหลัก
- แถบย่อย: แสดงสัญลักษณ์ไว้นอกวง
- เฉพาะดาวที่อยู่ในตารางความสัมพันธ์เท่านั้นที่จะแสดงเครื่องหมาย

## มุมมอง Timeline

Timeline เป็นมุมมองแนวนอน 2 ชั้น:

- ชั้นบน = แถบหลัก
- ชั้นล่าง = แถบย่อย
- ทุกช่วงกว้างตามระยะเวลาจริง
- มีเส้นบอกตำแหน่งอายุปัจจุบัน
- รองรับการเลื่อนแนวนอนบนมือถือ
