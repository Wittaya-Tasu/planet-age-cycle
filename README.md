# พระเคราะห์เสวยอายุ

WebApp โหราศาสตร์ไทยสำหรับคำนวณตำแหน่งพระเคราะห์เสวยอายุและพระเคราะห์แทรกบนวงจร 108 ปี

## เวอร์ชันปัจจุบัน

**v0.4.1 — Relation markers and image export**

| ฟังก์ชัน | สถานะ |
|---|---|
| วันเกิด 8 วันและเวลาเกิด | พร้อมใช้ |
| วงแหวนหลัก 8 ส่วน | พร้อมใช้ |
| วงแหวนย่อย 64 ส่วนตามสัดส่วนจริง | พร้อมใช้ |
| คำนวณช่วงด้วยปฏิทินจริง | พร้อมใช้ |
| วันเริ่ม–สิ้นสุดและเวลาที่เหลือ | พร้อมใช้ |
| คำพยากรณ์ | พร้อมใช้ |
| สัญลักษณ์ดี/ไม่ดีตามวันเกิด | พร้อมใช้ |
| วงกลมแสดงจุดเริ่ม | พร้อมใช้ |
| ลูกศรแสดงทิศทางอายุ | พร้อมใช้ |
| บันทึกภาพ PNG | พร้อมใช้ |
| PWA และ Offline | พร้อมใช้ |

## การใช้ระบบ

1. เลือกวันเกิดตามพระเคราะห์
2. กรอกวัน เดือน ปี พ.ศ. และเวลาเกิด
3. เลือกวันและเวลาเป้าหมาย หรือใช้เวลาปัจจุบัน
4. กด **คำนวณพระเคราะห์เสวยอายุ**
5. ดูแถบหลัก แถบย่อย วันเริ่ม วันสิ้นสุด และคำพยากรณ์
6. ชี้เมาส์หรือแตะแถบเพื่อดูรายละเอียด
7. กด **บันทึกภาพ** เพื่อดาวน์โหลดภาพ PNG

## ความหมายของเครื่องหมายบนวงแหวน

| เครื่องหมาย | ความหมาย |
|---|---|
| วงกลมล้อมเลขในแถบหลัก | พระเคราะห์จุดเริ่มตามวันเกิด |
| วงกลมสีขาวบนเส้นประ | จุดเริ่มเส้นทางอายุ |
| ลูกศร | ตำแหน่งและทิศทางอายุปัจจุบัน |
| ✓ | ความสัมพันธ์ที่ดีตามวันเกิด |
| ! | ความสัมพันธ์ที่ไม่ดีตามวันเกิด |
| ไม่มีสัญลักษณ์ | ไม่มีข้อมูลความสัมพันธ์ในตารางต้นฉบับ |

## ความเป็นส่วนตัว

ข้อมูลวันเกิดและการคำนวณเก็บในอุปกรณ์ด้วย `localStorage` ไม่มี Backend และไม่ส่งข้อมูลออกจากอุปกรณ์

## ทดสอบในเครื่อง

```bash
python3 -m http.server 8000
```

เปิด `http://localhost:8000`

## Automated Checks
