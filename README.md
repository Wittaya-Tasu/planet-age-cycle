# พระเคราะห์เสวยอายุ

WebApp คำนวณอายุเต็มจากวันเกิดถึงวันเป้าหมาย และแสดงจุดเริ่ม

## การใช้ระบบ

1. เลือกวันเกิดตามพระเคราะห์
2. ระบุวันที่ เดือน และปีเกิด พ.ศ.
3. ตรวจวันเป้าหมาย ระบบกำหนดเป็นวันปัจจุบันให้อัตโนมัติ
4. กด **คำนวณพระเคราะห์เสวยอายุ**
5. ดูอายุเต็มตรงกลางวงแหวน
6. จุดโปร่งคือจุดเริ่มจากวันเกิด จุดทึบคือตำแหน่งตามอายุ
7. กด **แก้ไขข้อมูล** เพื่อเปลี่ยนวันเกิดหรือวันเป้าหมาย
8. กด **รีเซ็ต** เพื่อลบข้อมูลในอุปกรณ์และกลับหน้าเริ่มต้น

## วิธีคำนวณอายุ

อายุที่แสดงตรงกลางวงแหวนเป็นอายุปฏิทินเต็ม:

```text
วันเกิด → วันเป้าหมาย = ปีเต็ม + เดือนเต็ม + วันที่เหลือ
```

การวางตำแหน่งบนวงจรใช้หน่วยโหราศาสตร์เดิม:

```text
cycleAgeYears = ปีเต็ม + เดือน ÷ 12 + วัน ÷ 360
```

ตัวอย่าง ผู้เกิดวันอาทิตย์อายุ 25 ปี:

- ผ่านพระอาทิตย์ 6 ปี
- ผ่านพระจันทร์ 15 ปี
- อยู่ในพระอังคารปีที่ 4
- ตำแหน่งตรงกับจุดเริ่มแถบย่อยพระราหูแทรกพระอังคาร

เมื่ออายุครบ 108 ปี ระบบเริ่มวงจรรอบใหม่และแสดงจำนวนรอบที่ผ่าน

## ข้อมูลที่บันทึก

วันเกิดและวันเป้าหมายเก็บด้วย `localStorage` ภายในอุปกรณ์เท่านั้น:

- ไม่มี Backend
- ไม่ส่งข้อมูลออกจากอุปกรณ์
- ปิดและเปิด WebApp ใหม่ ข้อมูลยังอยู่
- กด **รีเซ็ต** เพื่อลบข้อมูล

## เปิดทดสอบในเครื่อง

```bash
python3 -m http.server 8000
```

แล้วเปิด `http://localhost:8000`

## รัน Automated Checks

ต้องมี Node.js 18 ขึ้นไป:

```bash
npm test
```

ชุดทดสอบครอบคลุม:

- ข้อมูลพระเคราะห์หลักและแถบย่อย
- สูตรและผลรวม 108 ปี
- วันที่ พ.ศ. และวันสิ้นเดือน
- ปีอธิกสุรทิน
- อายุเต็ม ปี เดือน วัน
- การจับคู่วันเกิด 8 วัน
- จุดเริ่ม ตำแหน่งแถบหลัก และแถบย่อย
- กรณีตัวอย่างวันอาทิตย์อายุ 25 ปี
