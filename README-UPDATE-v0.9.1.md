# วิธีอัปเดต มหาทศา v0.9.0 → v0.9.1

## วิธีอัปเดต

1. แตก ZIP `maha-thasa-v0.9.1-update-only.zip`
2. อัปโหลดไฟล์ทั้งหมดขึ้นทับของเดิมใน Repository
3. Commit changes
4. รอ GitHub Pages deploy
5. ปิด WebApp เดิมทุกแท็บ แล้วเปิดใหม่ หรือ Hard Refresh หนึ่งครั้ง

## สิ่งที่ควรเห็นหลังอัปเดต

- เส้นประความสัมพันธ์ในหน้าผลประจำปีเป็นแนวนอน
- ไม่มีเครื่องหมายถูก / ตกใจในแผนภาพ annual view
- แท่งอนุทักษาแสดงเลขดาวเพียงครั้งเดียวต่อช่วง และมีชื่อกาลโยคชิดซ้าย
- วันที่ของอนุทักษาไปอยู่ที่รอยต่อของแต่ละช่วง
- แท่งเสวยหลักแสดงเลขอายุไว้ด้านล่าง
- Service Worker cache เปลี่ยนเป็น `maha-thasa-v0.9.1`
